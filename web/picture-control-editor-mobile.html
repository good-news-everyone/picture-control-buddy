NP3 profile editor

—
Approximate calculation in the browser — not an exact NX Studio render.

Gestures

Touch and hold the photo — view neutral (before/after)
Double-tap a slider — reset to default
Tap the value — type an exact number

Known limitations

Neutral development is calibrated for the Nikon Z f.
NEF High Efficiency RAW is not supported — convert it to DNG (without JPEG XL) first.
On iOS pick RAW files from Files: the Photos library may hand over a converted JPEG.

    Reset the whole profile?

    All settings return to neutral. The name is kept. You can undo it.

    Unsupported browser

    This editor needs WebGL2 with floating-point render targets. Try a current Firefox or Chrome.
